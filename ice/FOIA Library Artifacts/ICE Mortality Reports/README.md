# Archived ICE Mortality Reports

This folder contains mortality reports that U.S. Immigration and Customs Enforcement uploaded to its FOIA Library (https://www.ice.gov/foia/library) on or about Friday, September 25, 2026.

The reports have since been removed from the FOIA Library. The reason for their removal is not known.

We have archived the deleted files in this folder so they remain publicly available.
